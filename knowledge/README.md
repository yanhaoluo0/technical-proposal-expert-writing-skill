## 技术卡片格式

每个知识文件 = 一张「技术卡片」，标题即技术点，固定八段：

1. **适用场景与触发词**：什么项目/功能点命中本卡片
2. **技术内涵与边界**：做什么、不做什么（防止边界外滥用）
3. **典型架构与关键机制**：组件、协议、数据流、时序
4. **关键设计决策与权衡**：为什么这么选、备选方案与代价
5. **工程化要点**：配置、部署、监控、灰度、回滚
6. **指标映射**：能支撑哪些指标（可用性、性能、容量…）与量化口径
7. **标书化叙述示例**：一段可直接借鉴的「深」示例
8. **风险与边界**：常见失败模式与不可编造项

卡片用于补「深度」，用户素材用于补「实事」；冲突时以用户素材为准。
