# 01 计划阶段

先读 [../writing-guidelines.md](../writing-guidelines.md)。模板根路径：`文档示例/01 计划阶段/`。

## 可行性分析

**模板**：`00 可行性分析/可行性分析 - 模板.docx`  
**示例**：`00 可行性分析/可行性分析 - 示例.docx`

### 大纲（不得缺章）

1. 文档介绍（五节，见 writing-guidelines）
2. 项目介绍
   - 2.1 项目说明
   - 2.2 项目背景
   - 2.3 项目目标（可验收，避免「提升效率」空话）
   - 2.4 项目范围（含/不含）
   - 2.5 项目风险
   - 2.6 假设与限制
3. 现状与建设要求
   - 3.1 用户分析
     - 3.1.1 用户结构与管理职能
     - 3.1.2 用户类别与其说明（用表）
     - 3.1.3 用户环境（操作系统 / 网络环境 / 与其他软件的兼容性）
   - 3.2 当前业务流程
   - 3.3 当前数据状况
   - 3.4 建设任务与要求
4. 竞品项目现状（至少 2 个竞品，未知则「待确认」并保留小节）
   - 运营公司、业务开展、公司网站

|---|---|---|---|---|

### 检查清单

- [ ] 封面 + 变更履历
- [ ] 目标可验收；范围有边界
- [ ] 风险有对应假设/限制，不是只写「存在风险」
- [ ] 用户类别表填了角色简称
- [ ] 竞品保留规定小节，未改成 SWOT 论文结构

## 项目信息表

**模板**：`01 项目信息表/项目信息表 - 模板.xlsx`（表名：项目基本信息表）

输出一张表，字段不得改名：

项目名称、合同编号、所属部门、项目经理、预计开始时间、预计结束时间、实际开始时间、实际结束时间、客户名称、配置库名称、配置库地址、备注。

另附「成果物列表」：序号、成果物名称、类型。

## 项目实施方案

**Word 模板**：`03 项目实施方案-Word版/项目实施方案 - 模板.docx`  
**PPT 模板**：`02 项目实施方案-PPT版/`（用户要 PPT 时用；默认仍先出与 Word 同结构的 Markdown）

### 大纲

1. 项目背景
2. 项目目标
3. 项目范围
4. 项目总体计划（表）
5. 项目组织架构
   - 5.1 项目职责分工
6. 项目风险点
   - 6.1 项目风险分析
   - 6.2 项目实施关键点
7. 项目管理规范
   - 7.1 项目实施约束
   - 7.2 项目变更冻结
   - 7.3 项目沟通

## 项目实施进度计划 / 进度简表

**计划模板**：`04 项目实施进度计划/项目实施进度计划- 模板.xls`  
**简表模板**：`05 项目实施进度简表/项目实施进度简表 - 模板.xlsx`

简表字段：项目名称、编写人、项目经理、编写日期；行项目为 序号、阶段名称、进度比例、预计开始/结束、工作内容、阶段成果物、负责人。

进度必须能加总理解（比例之和与阶段划分自洽）。不要只写「开发中」。
