# 99 其他过程文档

先读 [../writing-guidelines.md](../writing-guidelines.md) 的术语与禁止编造条款。模板：`文档示例/99 其他模板/`。

## 会议纪要

**模板**：`会议纪要 - 模板.docx`（无 Word 封面五节，按本表）

### 会议基本信息（字段不得缺）

会议类别（管理会议 / 技术会议）、会议日期、会议地点、会议主题、主持人、记录人、开始时间、结束时间、参会人。

### 正文顺序

1. 会议概述（目的、结论预告，一段）
2. 议题列表（议题 1…n）
3. 讨论内容（每个议题一段，禁止只写标题）
4. 问题汇总表
5. 会议总结（结论 1…n，必须可执行或可判定）
6. 会议签到表（单位、部门、姓名、签名；未知标「待确认」）

问题汇总表：

| 序号 | 内容 | 执行人 | 完成期限 | 处理意见/完成情况 | 验证人 |
|---|---|---|---|---|---|
| 1 |  |  |  |  |  |

结论不能是「大家达成共识」；要写决定了什么、谁负责、何时完成。

## 项目周报

**模板**：`项目周报 - 模板.xlsx`

字段：项目名称、项目经理、项目阶段、当前 WBS 文件版本、项目总体进度、项目状态、起止时间、进度（%）、预期进度（%）。

分块：

- 本周工作内容：任务描述、成果物
- 遇到的问题及解决方法
- 需领导协调解决的问题和建议
- 下周工作计划
- 异常原因（进度落后时必填）

进度（%）与预期进度（%）必须同时给；落后时异常原因不能空。

## 项目月报

**模板**：`项目月报 - 模板.xlsx`（工作表：项目概述、项目月报）

**项目概述**：工程概况、项目建设目标、项目建设内容。  
**项目月报**：在周报字段基础上增加「近期项目节点」（节点名称、时间点）和「可能存在的风险及应对措施」（风险类型、风险描述、应对措施）。本月/下月口径替换本周/下周。

## 项目进度简报

**模板**：`项目进度简报 - 模板.docx`

Word 类：封面 + 变更履历 + 文档介绍五节，然后：

1. 文档介绍
2. 项目清单
   - 2.1 在建项目
   - 2.2 结项项目
3. 项目进度及问题跟踪（按项目分节）
4. 总结

标题可用 `项目进度简报-{部门}（YYYY年MM月）`。

## 工时统计表 / 进度确认单

按对应 xls 模板的列填写。不要改成自由叙述。工时行必须能对上人员、日期、任务；确认单必须有确认人字段位置（未知则「待确认」）。

## 检查清单

- [ ] 纪要有议题讨论 + 问题表 + 可执行结论
- [ ] 周报/月报同时有实际进度与预期进度
- [ ] 落后有异常原因；需领导协调的事项单独列出
- [ ] 无编造工时或百分比
