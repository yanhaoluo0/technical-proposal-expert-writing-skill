# 测试报告

与 SKILL.md 通用书写要求同时生效。仅在匹配到本场景后读取。

适用于测试报告、测试总结、测试说明。用叙述串起范围、方法、结果与结论。数据用表，表前后用文字归纳。无真实数据时数字写「待确认」，结论写「数据待填」；禁止编造通过率与缺陷数。

## 大纲

1. **概述**：目的、范围、环境、参与方、读者
2. **测试策略与方法**：类型（功能/性能/安全等）、方法、用例设计思路、通过/失败准则（可判定）
3. **测试执行与结果**：执行概况、通过率与主要结论；重要缺陷或风险单独成段
4. **结论与建议**：总体结论、遗留风险、改进或后续测试建议

## 输出

每次完整一节。约每 1000 个中文字符暂停确认。文件增量追加。

## 匹配后说明

已匹配测试报告。请提供测试范围、已有数据或希望先写的章节。
