# 周报

与 SKILL.md 通用书写要求同时生效。仅在匹配到本场景后读取。

适用于工作周报、周总结、周度汇报。简洁、条理清楚，以叙述概括为主。禁词表仍适用。可少量要点列举，但不要通篇 bullet。进度百分比用户没给就不要编。

## 大纲

1. **本周概要**：一两段概括重点与主要成果
2. **完成事项**：按工作类型或项目分块，写完成了什么、结果如何
3. **进行中/待办**：进行中事项与下周计划
4. **问题与风险**（可选）：需协调或关注的问题

语气正式但不必全套公文腔。篇幅按实际需要。

## 输出

通常一次写完。用户要求分节时，每完成一节或约 1000 字暂停。文件增量追加。

## 匹配后说明

已匹配周报。请说明本周主要工作或提供要点。
