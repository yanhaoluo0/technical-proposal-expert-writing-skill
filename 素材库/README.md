# 素材库（项目实事素材）

本目录用于放**本项目/当前写作任务特有的实事素材**，例如：

- 招标文件摘编、评分办法、技术规范
- 历史标书、方案初稿
- 甲方提供的接口文档、数据字典、架构说明

**通用技术深度素材不放在这里**——已统一迁移到 `knowledge/`（技术卡片 + GJB 438C 文档模板），写作时按技术点/指标关键词选择性检索；全部素材来源见 [knowledge/00-来源登记.md](../knowledge/00-来源登记.md)。

## 使用

1. 把素材放进本目录（仅 `.md` / `.txt`，UTF-8 或 GBK 均可，允许建子目录）
2. 运行索引脚本（无参数）：`python <skill目录>/scripts/index_materials.py`，生成 `素材库/.index.json`
3. 写作时 skill 自动检索：**项目素材命中后全文读取**；与内置知识冲突时以项目素材为准

注意：素材可能含敏感信息，索引与素材默认不应提交到公开仓库（`.index.json` 已在 .gitignore 中）。
