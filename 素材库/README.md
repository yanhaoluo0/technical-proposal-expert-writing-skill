# 素材库（模板与说明）

本目录是「素材库」的模板，**不需要**把素材长期放在 skill 仓库里；素材只在当前写作项目内使用，项目结束后随项目保留或清理。

实际写作时：

1. 在写作项目的工作目录下创建同名文件夹 `素材库/`（或把本目录复制过去）
2. 把素材放进去（仅 `.md` / `.txt`，UTF-8 或 GBK 均可，允许建子目录）。建议放：招标文件摘编、技术规范、历史标书、架构说明、通用技术文档
3. 从项目目录运行索引脚本（**无参数**）：`python <skill目录>/scripts/index_materials.py`，生成 `素材库/.index.json`
4. 写作时 skill 自动检索：用户素材命中后**全文读取**；与内置知识冲突时以素材为准

注意：素材可能含敏感信息，索引与素材默认不应提交到公开仓库（`.index.json` 已在 .gitignore 中）。
